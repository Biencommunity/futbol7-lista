Futbol 7 - Lista de Jugadores

Formulario para que hasta 16 jugadores se apunten a un partido de futbol 7. Cada jugador puede borrar solo su propia inscripcion; los administradores del sitio pueden editar la fecha, la hora y borrar a cualquiera. La lista se actualiza sola cada pocos segundos.

Este proyecto se distribuye como un plugin de WordPress (necesita base de datos y roles de usuario, algo que GitHub Pages no ofrece por si solo). Esta pagina es solo la ficha informativa del repositorio.

Instalacion

  1. Descarga el codigo desde el repositorio de GitHub.
  2. Comprime la carpeta futbol7-lista/ en un .zip.
  3. En WordPress: Plugins > Anadir nuevo > Subir plugin, sube el zip y actívalo.
  4. Anade el shortcode [futbol7_lista] en cualquier pagina.

Detalles completos en el README.md del repositorio.
